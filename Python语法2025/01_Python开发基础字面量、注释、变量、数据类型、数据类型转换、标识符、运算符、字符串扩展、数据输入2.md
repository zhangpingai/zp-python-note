## 字面量与注释
### 字面量（对应：`01_字面量.py`）
- 字面量是代码里直接写下来的固定值。
- 常见：整数、浮点数、字符串、布尔值。

```python
print(666)
print(13.14)
print("人生苦短，我用Python")
print(True)
```

可验证结果：

```text
666
13.14
人生苦短，我用Python
True
```

检查点：字符串必须加引号，`True/False` 首字母大写。

### 注释（对应：`02_注释.py`）
- 单行注释：`#`
- 多行说明常用三引号（教学中用作说明块）

```python
# 单行注释
"""
多行说明
"""
print("注释不会被执行")
```

可验证结果：

```text
注释不会被执行
```

### 风险提醒
- 中文引号、全角标点会触发语法错误。

### 考试/面试易错点
- 把三引号字符串完全等同“注释语法”。

### 本节小结
- 字面量提供数据，注释提升可读性。

## 变量与数据类型
### 变量基础（对应：`03_变量的基础使用.py`）
- 语法：`变量名 = 值`
- 变量可重复赋值，后值覆盖前值。

```python
money = 50
name = "周杰伦"
print(money, name)
money = 10
name = "林俊杰"
print(money, name)
```

可验证结果：

```text
50 周杰伦
10 林俊杰
```

### 变量复用（对应：`04_变量的重复应用.py`、`05_变量的基础应用2.py`、`06_变量练习题.py`）
- 用变量避免重复硬编码。
- 变量可以参与表达式运算。

```python
money = 50
print("初始余额：", money)
money = money - 10 - 5
print("最终余额：", money)
```

可验证结果：

```text
初始余额： 50
最终余额： 35
```

### type 查看类型（对应：`07_type查看数据类型.py`）

```python
print(type(666))
print(type(12.345))
print(type("python666"))
age = 11
height = 172.55
print(type(age))
print(type(height))
```

可验证结果（核心）：

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'int'>
<class 'float'>
```

### 风险提醒
- `name`（变量）和 `"name"`（字符串）不是同一个概念。

### 考试/面试易错点
- 变量不是固定类型，变量里“当前存的数据”有类型。

### 本节小结
- 变量负责保存与复用数据，`type()` 负责验证数据类型。

## 数据类型转换
### 类型转换基础（对应：`08_数据类型转换.py`）
- `int(x)`：转整数
- `float(x)`：转浮点
- `str(x)`：转字符串

```python
t1 = str(123)
t2 = float(123)
t3 = int("123")
t4 = float("123.65")
print(type(t1), type(t2), type(t3), type(t4))
```

可验证结果：

```text
<class 'str'> <class 'float'> <class 'int'> <class 'float'>
```

### 错误场景验证（对应：`08_数据类型转换.py`）

```python
# print(int("haha123"))      # ValueError
# print(float("haha123"))    # ValueError
```

可验证现象：取消注释后会报 `ValueError`。

### 风险提醒
- `int(123.65)` 不是四舍五入，而是直接截断为 `123`。

### 考试/面试易错点
- 不清楚 `input()` 默认返回 `str`，导致后续运算报错。

### 本节小结
- 转换是“输入处理”和“字符串拼接”的关键桥梁。

## 标识符与运算符
### 标识符命名规则（对应：`09_标识符的命名规则.py`）
- 允许字母、数字、下划线（不建议中文命名）。
- 不能数字开头。
- 不能用关键字。
- 大小写敏感。

```python
user_name = "alice"
age1 = 18
Age1 = 20
print(user_name, age1, Age1)
```

可验证结果：`age1` 与 `Age1` 是两个不同变量。

### 算术运算符（对应：`10_数学（算术）运算符.py`）
- `+ - * / // % **`

```python
a = 7
b = 3
print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

可验证结果：

```text
10
4
21
2.3333333333333335
2
1
343
```

### 风险提醒
- `/` 与 `//` 结果不同，别混用。

### 考试/面试易错点
- `%` 既用于求余，也用于字符串格式化。

### 本节小结
- 命名规则保证代码“能运行”，运算符规则保证结果“算得对”。

## 字符串扩展
### 三种写法（对应：`11_字符串的三种写法.py`）
- 单引号、双引号、三引号。

### 加号拼接（对应：`12_字符串的加号拼接.py`、`13_字符串加号拼接练习题.py`）

```python
name = "张三"
age = 11
info = "我是" + name + "，今年" + str(age) + "岁"
print(info)
```

可验证结果：

```text
我是张三，今年11岁
```

### `%` 占位格式化（对应：`14_字符串%占位格式化.py`、`15_字符串%占位符练习题.py`）

```python
name = "张三"
age = 11
height = 172.55
print("我是%s，今年%d岁，身高%.2fcm" % (name, age, height))
```

### 精度控制（对应：`16_字符串格式化精度控制.py`、`17_字符串格式化精度控制练习题.py`）

```python
money = 52.569
print("%7.1f" % money)
print("%.2f" % money)
print("%.0f" % money)
print(int(money))
```

可验证结果：

```text
   52.6
52.57
53
52
```

### f-string（对应：`18_字符串格式化方式2.py`、`18_字符串格式化方式2练习题.py`）

```python
name = "张三"
salary = 18000.55
print(f"我是{name}，工资{salary:.1f}")
```

### 表达式格式化（对应：`19_表达式的格式化.py`）

```python
age = 11
print(f"两年后年龄：{age + 2}")
```

### 风险提醒
- `str + int` 会触发 `TypeError`，先 `str()` 再拼接。

### 考试/面试易错点
- `%f` 默认保留 6 位小数，经常记错。

### 本节小结
- 字符串扩展本质是“把数据清楚地表达给人看”。

## 数据输入与综合案例
### input 基础（对应：`21_input输入.py`）
- `input()` 阻塞等待输入。
- 返回值一定是字符串。

```python
value = input("请输入内容：")
print(value, type(value))
```

可验证结果：无论输入数字还是文字，类型都是 `<class 'str'>`。

### 输入后转换再计算（对应：`21_input输入.py`）

```python
age = int(input("请输入年龄："))
print(age + 10)
```

可验证结果：输入 `18`，输出 `28`。

### 欢迎登录小程序（对应：`22_欢迎登陆小程序练习题.py`）

```python
username = input("账号：")
city = input("城市：")
print(f"欢迎你，{username}，当前城市：{city}")
```

### 股价综合练习（对应：`20_股价计算小程序练习题.py`）

```python
stock_price = 6.5
factor = 1.2
days = 7
result = stock_price * factor ** days
print("增长后股价：%.2f" % result)
```

可验证结果：输出约 `23.29`。

### 风险提醒
- 交互程序最常见错误：输入后未转换类型就参与计算。

### 考试/面试易错点
- 能写流程但解释不清“为什么要转换类型”。

### 本节小结
- 到这里你已经具备“可交互基础程序”能力。
