## 字面量与注释
### 字面量：代码中直接写下来的值
- 数字字面量：`int`、`float`
- 字符串字面量：必须加引号
- 布尔字面量：`True`、`False`

```python
print(666)        # int
print(13.14)      # float
print("人生苦短，我用Python")  # str
print(True)       # bool
```

预期输出：

```text
666
13.14
人生苦短，我用Python
True
```

检查点：`True` 首字母必须大写；字符串必须带引号。

### 注释：写给人看的解释，不参与执行
- 单行注释：`#`
- 多行说明：三引号字符串常用于文档说明（教学中可视为多行注释风格）

```python
# 这是单行注释
"""
这是多行说明
用于解释代码意图
"""
print("注释不会阻止这行被执行")
```

预期输出：

```text
注释不会阻止这行被执行
```

检查点：注释内容不在终端输出中出现。

### 字符串字面量的三种写法
- 单引号：`'abc'`
- 双引号：`"abc"`
- 三引号：`'''abc'''` 或 `"""abc"""`

```python
a = '单引号'
b = "双引号"
c = """三引号字符串"""
print(a, b, c)
print(type(a), type(b), type(c))
```

预期输出（类型顺序一致即可）：

```text
单引号 双引号 三引号字符串
<class 'str'> <class 'str'> <class 'str'>
```

### 风险提醒
- 全角符号（中文引号、中文括号）混进代码会直接报语法错误。

### 考试/面试易错点
- 误以为三引号只能做注释，实际上它首先是字符串。

### 本节小结
- 字面量是“数据本体”，注释是“代码说明书”。

## 变量与数据类型
### 变量是什么
- 变量是“带名字的存储位”。
- 赋值语法：`变量名 = 值`
- 可重复赋值（变量值可变）。

```python
money = 50
name = "周杰伦"
print(money, name)

money = 10
name = "林俊杰"
print(money, name)
```

预期输出：

```text
50 周杰伦
10 林俊杰
```

检查点：后一次赋值会覆盖前一次值。

### 为什么用变量
- 避免重复写死数据（硬编码）
- 便于统一修改
- 便于表达业务语义

```python
name = "刘德华"
print(name)
print(name)
print(name)
```

预期输出：

```text
刘德华
刘德华
刘德华
```

检查点：改一次变量值，所有输出同步改变。

### 用 type() 查看数据类型
- `type(值)` 或 `type(变量)`
- 初学重点：`str`、`int`、`float`

```python
print(type(666))
print(type(12.345))
print(type("python666"))

age = 11
height = 172.55
print(type(age))
print(type(height))
```

预期输出（核心是类型名）：

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'int'>
<class 'float'>
```

检查点：`type(age)` 看的是 `age` 当前保存的数据类型。

### 风险提醒
- `name`（变量）和 `"name"`（字符串字面量）不是一回事。

### 考试/面试易错点
- 说“变量本身有固定类型”不准确；更准确是“变量当前绑定的数据有类型”。

### 本节小结
- 变量让数据可复用，`type()` 让类型可观察可验证。

### 本节练习

2. 进阶题：输出这 3 个变量的类型信息。

## 数据类型转换
### 为什么要转换
- 键盘输入默认是字符串。
- 计算前常需转成数字。
- 展示时常需再转回字符串。

```python
age_text = "18"
age_num = int(age_text)
print(age_num + 10)
print(type(age_num))
```

预期输出：

```text
28
<class 'int'>
```

### 常用转换函数
- `int(x)`：转整型
- `float(x)`：转浮点型
- `str(x)`：转字符串

```python
t1 = str(123)
t2 = float(123)
t3 = int("456")
print(type(t1), t1)
print(type(t2), t2)
print(type(t3), t3)
```

预期输出（顺序一致即可）：

```text
<class 'str'> 123
<class 'float'> 123.0
<class 'int'> 456
```

### 转换失败场景
- 非纯数字字符串转数值会报错。

```python
print(int("haha123"))
```

预期现象：
- 报 `ValueError`，提示字符串无法按十进制转整数。

检查点：看到 `ValueError` 时先检查输入内容是否是纯数字。

### float 转 int 的行为
- 不是四舍五入，是直接截断小数部分。

```python
print(int(123.99))
print(int(-3.8))
```

预期输出：

```text
123
-3
```

### 风险提醒
- 不做输入校验直接 `int()`，程序很容易中断。

### 考试/面试易错点
- 把 `int(12.9)` 说成 `13`（错误，实际 `12`）。

### 本节小结
- 类型转换是输入处理和字符串拼接的必备桥梁。

### 本节练习
1. 基础题：把 `"250"` 转成整数并加 `50` 输出。

3. 排错题：尝试 `float("abc")` 并说明报错原因。

## 标识符与运算符
### 标识符命名规则
- 允许：中文、英文、数字、下划线（教学上建议以英文和下划线为主）。
- 不能数字开头。
- 大小写敏感。
- 不能使用关键字（如 `True`、`False`、`if`）。

```python
user_name = "alice"
age1 = 18
Age1 = 20
print(user_name, age1, Age1)
```

预期输出：

```text
alice 18 20
```

检查点：`age1` 与 `Age1` 不同变量。

```python
True = 1
```

预期现象：
- 报 `SyntaxError`，关键字/常量名不可赋值。

### 算术运算符
- `+ - * / // % **`

```python
a = 7
b = 3
print(a + b)   # 10
print(a - b)   # 4
print(a * b)   # 21
print(a / b)   # 2.333...
print(a // b)  # 2
print(a % b)   # 1
print(a ** b)  # 343
```

预期输出：

```text
10
4
21
2.3333333333333335
2
1
343
```

检查点：`/` 结果是浮点数；`//` 才是整除。

### 风险提醒
- 初学者常把 `%` 只理解为“百分号”，忽略它在 Python 中也是求余与格式化符号。

### 考试/面试易错点
- 混淆 `/` 与 `//` 的返回结果类型。

### 本节小结
- 命名规则保证“能运行”，运算符规则保证“算得对”。

### 本节练习
1. 基础题：定义两个整数并输出加减乘除结果。
2. 进阶题：用 `**` 计算 `2` 的 `10` 次方。
3. 排错题：变量名改成 `1name`，观察并解释报错。

## 字符串扩展
### 字符串拼接：+ 与重复
- `str + str`：拼接
- `str * n`：重复

```python
print("程序员平安" + "666")
print("-" * 10)
```

预期输出：

```text
程序员平安666
----------
```

### 跨类型拼接报错与修复
- 字符串不能直接和 `int/float` 用 `+` 拼接。
- 先 `str()` 再拼接。

```python
name = "张三"
age = 11
height = 172.55
# 错误写法（示例，不执行）：
# info = "我是" + name + "，今年" + age + "岁，身高" + height + "厘米"
info = "我是" + name + "，今年" + str(age) + "岁，身高" + str(height) + "厘米"
print(info)
```

预期输出：

```text
我是张三，今年11岁，身高172.55厘米
```

检查点：出现 `TypeError: can only concatenate str ...` 时先看是否少了 `str()`。

### % 占位格式化
- `%s` 字符串，`%d` 整数，`%f` 浮点数

```python
name = "张三"
age = 11
height = 172.55
msg = "我是%s，今年%d岁，身高%.2f厘米" % (name, age, height)
print(msg)
```

预期输出：

```text
我是张三，今年11岁，身高172.55厘米
```

### 精度控制（m.n）
- `%7.2f`：总宽度 7，小数 2 位
- `%.1f`：不限总宽度，小数 1 位

```python
money = 52.569
print("%7.1f" % money)
print("%.2f" % money)
print("%.0f" % money)
print(int(money))
```

预期输出：

```text
   52.6
52.57
53
52
```

检查点：`%.0f` 是四舍五入；`int()` 是截断。

### f-string（推荐）
- 语法更直观：`f"文本{变量}"`
- 支持表达式与精度控制：`{height:.1f}`

```python
name = "张三"
money = 100
salary = 18000.55
print(f"我是{name}，钱包余额{money}元，今天发工资{salary:.1f}元，当前总额{money + salary:.2f}元")
```

预期输出：

```text
我是张三，钱包余额100元，今天发工资18000.5元，当前总额18100.55元
```

### 风险提醒
- 花括号/引号不配对是字符串格式化最常见语法错误。

### 考试/面试易错点
- 不知道 `%f` 默认保留 6 位小数。

### 本节小结
- 字符串扩展的本质是“把数据清晰地表达出来”。

### 本节练习
1. 基础题：拼接“姓名+班级+目标”并输出。
2. 进阶题：分别用 `%` 和 `f-string` 输出同一条工资信息。
3. 排错题：故意写一个 `str + int` 的拼接，触发并修复 `TypeError`。

## 数据输入 input()
### input 基础
- `input()` 会阻塞，等待用户输入。
- 返回值永远是 `str`。

```python
name = input("请输入你的名字：")
print("你输入的是：", name)
print(type(name))
```

可验证结果（示例输入：`平安`）：

```text
请输入你的名字：平安
你输入的是： 平安
<class 'str'>
```

检查点：不管输入数字还是文字，`type` 都是 `str`。

### 输入后做数值计算
- 先转换再计算。

```python
age = int(input("请输入年龄："))
age += 10
print("10年后年龄：", age)
```

可验证结果（示例输入：`18`）：

```text
请输入年龄：18
10年后年龄： 28
```

### 输入综合示例：欢迎登录
- 同时用到输入、变量、格式化输出。

```python
user = input("请输入用户名：")
city = input("请输入城市：")
print(f"欢迎你，{user}，当前学习城市：{city}")
```

可验证结果（示例输入：`Alice`、`上海`）：

```text
请输入用户名：Alice
请输入城市：上海
欢迎你，Alice，当前学习城市：上海
```

### 风险提醒
- 用户输入非法数字会导致 `int()` 报错中断。

### 考试/面试易错点
- 误答“输入 18 得到 int 类型 18”（错误，原始返回是字符串）。

### 本节小结
- `input()` 让程序从“固定输出”升级为“与用户交互”。

### 本节练习
1. 基础题：输入姓名并输出“你好，xxx”。

3. 排错题：输入 `abc` 给 `int(input())`，观察报错并写出改进方案。

## 综合实战：从语法到小程序

### 实战 2：股价增长计算

```python
name = "程序员平安"

```

预期输出：

```text
公司：程序员平安，股票代码：003032，当前股价：6.5
每日增长系数：1.2，经过7天增长后，股价达到：23.29
```
